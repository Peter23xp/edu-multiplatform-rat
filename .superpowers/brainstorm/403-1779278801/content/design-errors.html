Design des Messages d'Erreur

Section 2/3 — Système de notifications contextuelles avec cause + suggestion d'action. 4 niveaux de sévérité.

Exemples de messages d'erreur — tous les cas possibles
Niveau: ERREUR (rouge)
✕ ERREUR — Connexion perdue RÉSEAU
14:32:05
Client: 192.168.1.10  ·  Opération: send_command  ·  Cause: Connection reset by peer (errno 104)
→ Le client s'est déconnecté brutalement. Vérifier que le processus client tourne toujours sur la machine cible. Le client tentera de se reconnecter automatiquement.
Niveau: AVERTISSEMENT (jaune)
⚠ AVERTISSEMENT — Webcam indisponible DÉPENDANCE
14:31:02
Client: 192.168.1.15  ·  Opération: capture_webcam  ·  Cause: Module opencv-python absent
→ Installer opencv sur le client cible: pip install opencv-python puis reconnecter.
Niveau: AVERTISSEMENT — Timeout
⏱ TIMEOUT — Commande sans réponse RÉSEAU
14:35:20
Client: 192.168.1.10  ·  Commande: whoami  ·  Délai: 15 secondes dépassées
→ Connexion lente ou client bloqué. Augmenter le timeout dans Paramètres → Réseau → Timeout, ou vérifier l'activité réseau.
Niveau: ERREUR — Permission
🔒 ERREUR — Permission refusée FICHIER
14:38:11
Client: 192.168.1.15  ·  Opération: download_file  ·  Chemin: /etc/shadow  ·  Cause: Permission denied (errno 13)
→ Le client n'a pas les droits nécessaires sur ce fichier. Vérifier que le processus client tourne en root/admin, ou choisir un fichier accessible.
Niveau: SUCCÈS (vert)
✓ SUCCÈS — Fichier téléchargé FICHIER
14:40:03
Client: 192.168.1.10  ·  Fichier: C:\Users\user\passwords.txt  ·  Taille: 2.4 KB  ·  Durée: 0.3s
Niveau: INFO (bleu)
ℹ INFO — Keylogger démarré SURVEILLANCE
14:41:30
Client: 192.168.1.10  ·  Opération: start_keylogger  ·  Statut: Enregistrement en cours

Structure d'un message d'erreur

Ligne 1: icône + niveau (ERREUR/AVERTISSEMENT/SUCCÈS/INFO) + titre court + badge catégorie (RÉSEAU / FICHIER / DÉPENDANCE / SURVEILLANCE) + horodatage
Ligne 2: Client IP · Opération · Cause exacte (errno, module manquant, chemin, etc.)
Ligne 3: Suggestion d'action concrète avec commande ou chemin cliquable si applicable
