Plan d'amélioration — Vue d'ensemble

3 sous-projets indépendants. Chacun apporte une amélioration concrète. On les fait dans l'ordre.

1 Robustesse C2 À FAIRE EN PREMIER
Problème actuel
• Client crash → données perdues
• Pas de reconnexion automatique
• Serveur croit le client vivant
• Pas de keepalive / heartbeat
Après fix
• Reconnexion exponentielle (1s→2s→4s…max 60s)
• Heartbeat toutes les 30s bidirectionnel
• Serveur détecte client mort en ~35s
• Watchdog relance le client si bloqué
2 Exfiltration automatique
Problème actuel
• Keylogger garde les données en RAM
• Clipboard jamais envoyé seul
• Screenshots uniquement sur demande
• Tout se perd si connexion coupe
Après fix
• Envoi auto keylogger toutes les 60s
• Clipboard envoyé si changement détecté
• File d'attente locale si pas de connexion
• Données sauvées sur disque (survie reboot)
3 Persistance discrète
Problème actuel
• Noms hardcodés (EduRAT_Service…)
• Un seul point de persistance
• Facile à détecter et supprimer
• Chemin absolu qui casse si déplacé
Après fix
• Noms générés aléatoirement
• 3 méthodes fallback si la 1ère échoue
• Vérification + réinstall automatique
• Chemins dynamiques basés sur l'env
