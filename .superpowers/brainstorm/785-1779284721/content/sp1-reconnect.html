Comment le client va se reconnecter seul et comment le serveur détecte les clients morts.

⚡ Reconnexion exponentielle
START → tente connexion
│
ÉCHEC → attente 1s
│
ÉCHEC → attente 2s
│
ÉCHEC → attente 4s
│ × 2 à chaque échec
PLAFOND → max 60s entre chaque essai
│
SUCCÈS → délai reset à 1s
# Avant (actuel)
while True:
  time.sleep(5) # fixe, bloque

# Après
delay = 1
while True:
  time.sleep(delay)
  delay = min(delay * 2, 60)
💓 Heartbeat bidirectionnel
CLIENT
Envoie PING toutes les 30 secondes
Thread séparé, non-bloquant
⇅
SERVEUR
Répond PONG immédiatement
Met à jour last_seen du client
🔍 Détection client mort
• Watchdog serveur tourne toutes les 10s
• Si now - last_seen > 35s → client marqué MORT
• Dashboard mis à jour automatiquement
• Log contextuel affiché dans la console GUI
